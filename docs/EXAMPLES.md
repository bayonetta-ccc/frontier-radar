# 示例输出导读

这里保存了由 `python -m frontier_radar demo` 真实生成的三期报告（未做人工润色）。
它们对应同一个任务：**固态电池 × 产业研究员 × 6 个月内形成路线建议**。

| 文件 | 期次 | 看点 |
|---|---|---|
| [01-baseline.md](examples/01-baseline.md) | 2026-07-28 | 首次基线：4 个待确认判断、1 条转载与 2 条噪声被拦截 |
| [02-update.md](examples/02-update.md) | 2026-08-08 | 4 个判断需要更新：1 条证伪、2 条增强、1 条转向；全部停在“待确认” |
| [03-quiet.md](examples/03-quiet.md) | 2026-08-15 | 本期无需更新；2 条热门/重复内容被拦截 |

> 数据是**合成 fixture**，链接为 `example.com` 占位；公司名称、时间与表述均为演示，
> 不代表真实新闻。报告顶部始终标注这一点。

## 一条证伪是怎么被拦下来的

`02-update.md` 的第一张变化卡：

```text
### 1. [证伪] 原判断已被否定，降级为待重建假设（依据：宝马澄清：QuantumScape 尚未完成整车级验证，仅处于样件测试阶段）

- **影响分**：100/100 ｜ **置信度**：0.54 → 0.20（-0.34） ｜ **阶段**：客户验证 → 客户验证 ｜ **待确认**
- **为什么变化**：出现 1 条高权重相反证据（合计 0.58），覆盖 1 个独立来源，
  且包含来自当事方的明确澄清；当前判断被足够可靠的材料否定。
  注意：目前仍只有单一来源组，结论需独立来源复核。
- **与我何干**：……这次证伪意味着不能再用“QuantumScape 已进入整车级客户验证阶段”作为前提：
  需要重新找证据，而不是继续加固旧结论。
- **仍不能确认**：本条变化尚未确认：需要用户核对证据后才会写入当前判断；……
- **相反证据** `fact`：宝马澄清：QuantumScape 尚未完成整车级验证，仅处于样件测试阶段
```

它体现了四件事：

1. **事实与判断分离**：宝马的澄清被标为 `fact`，系统据此下调的是“QuantumScape 已进入整车级验证”
   这个**判断**，不是把澄清本身当成结论；
2. **相反证据优先**：旧的支持证据被移出“当前依据”，证据台账只保留相反证据；
3. **诚实标注边界**：只有单一来源组时，系统明确提示“结论需独立来源复核”；
4. **人工确认闸门**：证伪不会自动写入，报告把“待确认”放在最前面。

## 一条“热门但没有实质进展”是怎么被拦下来的

`03-quiet.md` 的“本期没有推送的内容”：

- 标准草案征求意见的**转载** → 正文哈希与标题相似度识别为重复；
- 论坛讨论“宝马澄清之后……” → 匿名/未证实传闻，不单独构成判断更新依据。

同时摘要直接输出“本期无需更新”，而不是把同一件事换个说法再推一遍。

## 怎么复现

```bash
python -m frontier_radar demo
# 报告：data/artifacts/task_solid_state_2026/<run_id>/digest.md
# 站点：data/web/index.html
```

想看到“确认之后”的当前判断：

```bash
python -m frontier_radar demo --confirm-after
python -m frontier_radar claims list
python -m frontier_radar claims show clm_2026_quantumscape_validation
```
