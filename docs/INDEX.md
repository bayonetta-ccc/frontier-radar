## 30 秒理解这个项目

```text
信号（可能有噪声、重复、营销）
  → 去重 + 分类 + 阶段判定
  → 映射到“判断”
  → 证据门槛：够不够改？谁来确认？
  → 变化卡（变了什么 / 为什么重要 / 与我何干 / 下一步验证什么）
  → 判断状态库（版本、理由、可回滚）
```

它保存的不是文章，而是**当前相信什么，以及为什么现在还相信**。
